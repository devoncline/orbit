# Changelog

## Unreleased

### Improvements

- Talk It Through replies now appear as Orbit generates them, while Orbit keeps thinking until the response is complete. Interrupted replies preserve your message for retry; only complete conversations are saved for resume.
- Orbit now thinks with a gentle sway and varied contextual thoughts while preparing lessons, examples, activities, replies, and questions. Thought pairs change between requests and stay steady during each one, with one thought on phones, static visuals for reduced motion, and concise screen-reader announcements. Removed the decorative dot trail.
- Study now keeps your place visible in a compact, expandable path and suggests one useful next step as you explore, try an activity, or practice. Study tools stay close at hand without crowding the lesson, with a smaller path on phones and easy access to "I lost you." You can still choose another tool or continue whenever you are ready.
- Active lessons now share Orbit's page alignment, heading scale, and companion placement, with a clean background and compact Study threads / New thread controls. Removed the extra Back home row and session banners on other pages; Home and Learn still return to the active lesson.
- Learn now offers a guided lesson flow with a clear current lesson, optional readiness check, and a way to continue without taking a quiz. A compact, expandable learning path adapts to course materials, learner corrections, and study context; reading or moving forward does not increase mastery.
- Lessons, examples, and Muse replies are easier to scan with short sections, key concepts, and concrete examples. Conversations keep the current lesson in view, and recent lesson progress resumes in the same browser.
- Home, Learn, Calendar, Library, and learning spaces now share consistent heading, content, and companion placement on desktop and mobile. Removed the extra background behind Orbit and gave Library's local-data controls more breathing room.
- Home and Learn now have distinct starting experiences: Home offers class, curiosity, and material paths; Learn opens a focused topic entry that starts studying directly. Existing spaces can be reused, and active sessions resume through Learn.
- Orbit now remembers learning spaces, syllabus context, mastery, learner corrections, and useful learning anchors in the same browser. Home continues from recent work, with explicit corrections taking priority over inferred starting points.
- Recent study threads retain compact summaries, the latest lesson, and two recent exchanges after refresh. A confirmed Library control clears local learning data. Memory stays on this device, with relevant context used by the existing learning service; there is no account or cross-device sync.
- Mobile navigation now opens from a compact menu icon immediately before the Orbit logo, with an accessible label and a comfortable touch target.
- Study now keeps one interaction in focus, with compact access to earlier exchanges and separate study threads. Switching threads preserves live drafts, activities, quizzes, and learning context.
- Recommendations and new lessons use today's date and syllabus timing to suggest a relevant starting point. Learners can correct that position, skip familiar material, or say a topic has not started; unclear timelines ask for a starting point, and past material remains available for review.
- Actions across Orbit have clearer surfaces and hover/focus feedback, with fewer decorative arrows and easier-to-tap Study controls on mobile.
- Learn keeps the shared desktop sidebar. Orbit stays fully visible on small screens, smiles between replies, and uses the same gentle floating motion everywhere, switching to a thinking pose while preparing a response.
- Home now leads with the current learning task or question and a contextual action. Study gives Orbit a larger visual stage, with a dedicated mobile composition, calmer motion, and clearer controls. Calendar, Library, and space setup use simpler copy and more open layouts with fewer dividers.
- Orbit now has learning spaces for classes, skills, and personal interests, with a calm shared navigation, a mobile menu, and three ways to begin from an empty account. Home keeps one next action in focus and uses Orbit’s existing environment and companion artwork.
- A lightweight Calendar and Home preview gather dated work from learning materials, keeping unclear dates separate for review. Materials can be added directly to a chosen space, with visible upload progress and retry feedback.
- Study now has a quieter environment, clear Learn/Practice progress, and a way to return Home and resume the current session.
- Orbit can now remember useful connections, successful activities, and tentative misconceptions during study, then reuse relevant examples in later teaching and practice. These memories do not change mastery.
- Learn now offers "Let me try it": a short, practical activity based on the current concept and conversation. Learners can share what they tried, get focused feedback, and keep talking or choose "Quiz me". Activities stay in the current session and do not change mastery.
- Learners can now ask questions or share connections during a lesson and receive short, contextual replies from Orbit. The lesson shortcuts and "Quiz me" remain available, with recent conversation kept compact.
- Study sessions now begin with a short, topic-aware lesson. Learners can ask for a different explanation or a concrete example, then choose "Quiz me" to practice the concept before continuing through adaptive questions.
- Home now places its learning recommendation and companion in a nebula environment, with dark text areas, soft edges, and a quieter crop on smaller screens.
- Orbit now uses its own browser and app icons. The Home companion has a more noticeable, calm floating motion while remaining static for reduced-motion users.
- Home now features the Orbit logo and companion artwork, with gentle floating motion that respects reduced-motion preferences and compact placement on smaller screens.
- Home now puts the next learning action first, with a calmer dark palette, a responsive hero, and easy-to-scan courses below. Course details, adding courses, and uploading materials remain available below the recommendation.
- Study question generation now asks Muse to choose a relevant topic, preferring weaker topics when they relate to upcoming work.
- Study answers now update mastery for the question's topic, with overall course mastery calculated as the rounded average of topic scores. Questions without a topic retain the existing course mastery behavior.
